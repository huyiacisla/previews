How a resident chat works

  1. Step 1

    The assistant asks first

    The resident opens Messages and picks a topic or types a question. Staff see nothing yet.

  2. Step 2

    Hand-off, only if asked

    If the answer is not enough, the resident asks for a person. The request waits in the Staff queue with a summary.

  3. Step 3

    One person takes it

    A staff member takes the chat; only one can. The resident is notified when they join.

  4. Step 4

    Resolved, then closed

    Staff resolve it, or the resident ends it. The chat closes; the next visit starts with the assistant again.
